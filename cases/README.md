# 폭발물 사건 사례

국내외 공개 자료와 공식 조사·수사 기록을 바탕으로 주요 사건의 경과와 피해, 사용된 폭발물의 **공개 확인 범위**, 작동 분류, 대응 교훈을 정리합니다. 사건의 목적은 재현 가능한 제작법을 제공하는 것이 아니라 역사적 사실과 공공안전 교훈을 기록하는 데 있습니다.

## 읽을 때 유의할 점

- 폭약·기폭 분류는 출처가 확인해 주는 수준으로만 기재합니다. 상세한 조성비, 수량, 회로·배선, 조립 순서는 싣지 않습니다.
- 언론 보도와 공식 기록의 표현 또는 피해 집계가 다른 경우, 출처와 기준을 밝혀 구분합니다. 확인되지 않은 내용은 추정하지 않고 **공개 자료에서 확인되지 않음**으로 표시합니다.
- 현장에서 의심 물체를 발견하면 접근·이동·개봉하지 말고 안전한 거리에서 이탈해 112 또는 119에 신고해야 합니다.
