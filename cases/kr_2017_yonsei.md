# 연세대학교 연구실 폭발 사건 (2017)

> **요약:** 2017년 6월 13일 연세대학교 공학관에서 교수에게 전달된 포장물을 개봉하는 과정에 폭발이 발생해 교수가 다쳤다. 수사·재판 보도는 대학원생이 범행한 사건으로 기록한다.

## 사건 개요

| 항목 | 확인 내용 |
|---|---|
| 발생 일시 | 2017년 6월 13일 오전 |
| 장소 | 서울 연세대학교 제1공학관 내 교수 연구실 앞 |
| 사건 경과 | 교수 연구실 문 앞에 놓인 포장물을 열 때 폭발한 것으로 재판 보도에 기록됨 |
| 피해 | 교수 1명 부상. 구체적 상해 부위·정도는 보도마다 세부 표현이 달라 여기서는 단정하지 않음 |
| 수사·재판 | 피고인은 폭발성물건파열치상 혐의로 재판을 받음 |

## 폭발물·작동 방식: 공개 확인 범위

- **물건의 성격:** 재판 보도에서 텀블러가 포함된 폭발성 물건으로 다뤄졌다.
- **폭약 종류·정확한 조성:** 공개된 출처만으로 특정 조성과 양을 확정하지 않는다. 확인되지 않은 세부는 기재하지 않음.
- **작동 분류:** 포장물을 개봉하는 행위와 폭발이 연관된 것으로 보도됐다. 내부 스위치 구성이나 회로 작동 원리는 이 문서에서 추정하거나 재현 가능한 수준으로 기술하지 않는다.
- **특성:** 일상적인 포장·용기에 폭발 위험이 숨겨질 수 있고, 수취인이 직접 개봉하도록 유도되는 상황이 피해를 일으켰다는 점이 핵심이다.

## 피해와 대응상 시사점

1. **의심스러운 전달물은 개봉하지 않는다.** 예상하지 못한 물건, 발신자·전달 경위가 불분명한 물건은 현장에서 열거나 옮기지 말고 주변을 통제한 뒤 신고한다.
2. **위협 판단은 외관만으로 하지 않는다.** 평범한 용기나 포장이라는 이유로 안전하다고 간주할 수 없다.
3. **현장 증거를 보존한다.** 물건을 만지거나 내부를 확인하려 하지 말고, 발견 위치와 접근 경로를 기억해 대응기관에 전달한다.
4. **개인 갈등도 공공안전 위협으로 번질 수 있다.** 위협 징후를 조직의 안전·상담·신고 체계와 연결하는 예방 절차가 필요하다.
