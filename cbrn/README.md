# 화생방 위협과 안전 개요 ☣️

화생방(CBRN)은 화학(Chemical)·생물학(Biological)·방사성(Radiological)·핵(Nuclear) 위험을 아우르는 표현입니다. 이 문서는 위험 유형을 구분하고 의심 상황에서 일반인이 취할 기본적인 안전 행동을 안내합니다.

> **안전 원칙:** 정체를 알 수 없는 물질, 용기, 분말, 장치에 손대거나 냄새를 맡거나 옮기지 마십시오. 주변에 알리고 안전한 곳으로 이동한 뒤 112 또는 119에 신고하고, 현장 기관의 안내를 따르십시오. 이 페이지는 교육용 개요이며 현장 지휘·전문 대응 절차를 대체하지 않습니다.
